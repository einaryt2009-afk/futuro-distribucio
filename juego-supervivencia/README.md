# ZONA CERO — Supervivencia

Juego web de supervivencia desarrollado en HTML5 Canvas, CSS y JavaScript.

## Cómo jugar
- **WASD / Flechas:** moverse
- **Ratón:** apuntar
- **Click:** disparar
- **P:** pausa
- El objetivo es sobrevivir a oleadas cada vez más intensas.

## Características
- Oleadas progresivas
- Enemigos normales y élite
- Puntuación y récord local
- Sistema de vida y curación
- Partículas, cámara con impacto y sonido procedural
- Diseño responsive para pantallas pequeñas
- Sin librerías externas ni assets de terceros

La carpeta del juego está separada del resto del proyecto.
